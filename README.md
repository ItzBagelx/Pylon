# Pylon

A live dashboard for Great Britain's electricity grid: generation mix, carbon intensity, interconnector flows, Octopus Agile prices, wholesale prices and installed capacity.

Live site: https://itzbagelx.github.io/pylon/

Data: NESO Carbon Intensity API (CC BY 4.0), Elexon Insights Solution, Octopus Energy API. Capacity figures from DESNZ statistics.
